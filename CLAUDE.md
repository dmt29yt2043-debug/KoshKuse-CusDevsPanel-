## Правила

- **Персональные данные.** Аудио, транскрипты, имена тестеров — в git не кладём никогда.
  Локально — `data/` и `samples/` (в `.gitignore`). В тестах — только выдуманные тексты.
- **Закрытые списки** (СКЮ, темы, форматы, вердикты, каналы) — только `config/taxonomy.yaml`.
  В коде и в промптах не перечислять значения руками — брать из `get_taxonomy()`.
- **Цитаты — только через `sanitize()`.** Ничего, что модель вернула, не пишется в базу в обход.
- **Без облачного распознавания**, анкет, Telegram-бота, ролей (границы прототипа в ТЗ).
- Интерфейс и сообщения — по-русски. Цифры на дашборде — абсолютные, без процентов и трендов.
- Стек: Python 3.12, `uv`, FastAPI, Jinja2 + ванильный JS без сборки, SQLAlchemy 2 + SQLite.
  Docker на Маке нет — локально всё через `.venv/bin/...`; Docker только на VPS.
- Перед коммитом: `.venv/bin/ruff check . && .venv/bin/ruff format --check . && .venv/bin/pytest -q`.
- Коммиты — по-русски, одной фразой о том, что изменилось для пользователя.
